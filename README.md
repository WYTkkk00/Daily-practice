# Daily-practice

重庆大学 C 语言课程练习记录。

## 文件说明
- `calc_pi.c`     — 用莱布尼茨级数计算 π
- `sum_line.c`    — 数列求和
- `agri_tower.c`  — 鸡兔同笼 / 牛吃草类问题
- `weekwork.c`    — 周次字符串转换
- `ChooseShoter.c`  _从A,B中选择更好的射手
- `figr-aph.c`    _输出一个字符串中出现最多次的字母
- `anti-output.c`_反向输出一个字符串
- `BIG-small-trans.c`    _大小写转换
- `matr-2.c`    _矩阵输出
- `move-5.c`    _5位字符串的调序
- `ABCcycle.c`  _围着一圈报字母
- `10-2-trans`  _十进制转二进制

## 编译运行
gcc xxx.c -o xxx && ./xxx
